Design a complete, modern, elegant, and responsive Virtual Assistant portfolio website with a separate secure Admin Dashboard for managing website content.

## PROJECT OVERVIEW

Create a professional personal portfolio website for a female Virtual Assistant whose main expertise is:

* Customer Service
* Email Management
* Administrative Support
* Customer Communication
* Calendar and Appointment Management
* Data Entry
* Social Media Assistance

The website should attract potential clients, showcase her experience, build trust through testimonials, and allow visitors to contact her for business inquiries.

The website must have two separate experiences:

1. Public Client-Facing Portfolio Website
2. Private Admin Dashboard for the Virtual Assistant

Use the attached reference image as inspiration for the overall portfolio structure, elegant typography, editorial layout, personal branding, and professional presentation. Do not copy the reference exactly. Create a unique, modern design with baby pink and sage green colors.

## DESIGN STYLE

Design direction:

* Feminine but professional
* Clean and minimal
* Elegant editorial portfolio
* Warm and welcoming
* Soft luxury aesthetic
* Modern responsive website
* Easy to navigate
* Strong emphasis on customer service and email management

Avoid:

* Overly colorful designs
* Excessive animations
* Cluttered layouts
* Very dark or corporate-looking themes
* Excessive rounded cards
* Generic stock-business website appearance

## COLOR PALETTE

Primary colors:

* Baby Pink: #F8DDE5
* Soft Blush: #F3C8D4
* Sage Green: #A8BFA5
* Deep Sage Green: #6F8970
* Dark Forest Green: #354238
* Warm Cream: #FFF9F5
* Soft Beige: #EDE4DC
* Charcoal Text: #30332F

Use baby pink for highlights, soft backgrounds, buttons, and subtle accents.

Use sage green for primary action buttons, navigation accents, icons, and selected states.

Use cream and white for the main page backgrounds.

Maintain good color contrast and accessibility.

## TYPOGRAPHY

Use an elegant serif font for large headings and a clean sans-serif font for body text.

Suggested font pairing:

* Playfair Display or Cormorant Garamond for headings
* Inter, DM Sans, or Manrope for body text

Use:

* Large editorial hero headings
* Clear section labels
* Readable body paragraphs
* Consistent typography hierarchy
* Professional spacing and alignment

## RESPONSIVE DESIGN

Create designs for:

* Desktop: 1440px wide
* Tablet: 768px wide
* Mobile: 390px wide

Ensure the layout adapts properly to different screen sizes.

Use:

* Responsive grids
* Flexible containers
* Proper spacing
* Mobile navigation menu
* Stacked cards on mobile
* Responsive images
* Readable typography
* No horizontal overflow

Create reusable components and use Auto Layout, Components, Variants, and responsive constraints in Figma.
